可用工具（36）：
- adjust_image: 按显式参数调整图片亮度/对比度/饱和度/色温，返回调整后的图片。
- ai_optimize: AI 一键优化图片。
- change_language: 切换语言。
- change_theme: 切换主题。
- delay: 等待指定毫秒。
- delete_media: 删除媒体。
- download_model: 下载模型。
- draw_chart: 仅在用户明确要求画图时调用：画出图表并渲染成真实图片展示给用户——这是展示图表的唯一方式，严禁用文字、Markdown 表格、ASCII/emoji 画图（文字画的图用户看不到效果）。
- edit_image: 对话式图片编辑（美颜/滤镜/调色），后台完成并把结果图发到聊天中，**绝不跳转到编辑页**。
- exclude_constraint: 在后续搜索中排除某类约束，如'不要夜景'。
- favorite_media: 收藏/取消收藏媒体。
- finish: 任务完成时调用，提供完成摘要给用户。
- forget_fact: 忘记一条事实，如用户说「忘掉花粉过敏那条」。
- forget_person_relation: 忘记与某人物的全部关系，如用户说「忘掉小宝的关系」。
- get_gallery_summary: 获取本地相册摘要：照片/视频/媒体总数、含人脸数、人物聚类数、已/未打标数、语义向量数、扫描建议。
- go_back: 返回上一页。
- launch_app: 打开外部应用。
- list_person_relations: 查询已记住的人物关系。
- more_like_this: 基于指定图片推荐更多相似照片。
- navigate_to: 导航到页面。
- open_system_settings: 打开系统设置页。
- recall_memory: system prompt【关于用户】段已含常见记忆，优先直接引用；本工具仅在该段未列全（被截断）或需拿 factId 删除时调用。
- record_feedback: 记录用户对搜索结果的反馈。
- refine_media_search: 在上一轮搜索结果内细化过滤，如'只要夜景''找找4月的'。
- remember_fact: 记住一条事实，如用户说「帮我记住小宝对花粉过敏」「记住我喜欢低饱和度滤镜」。
- remember_person_relation: 记住人物与「我」的关系，如用户说「小宝是我女儿」「大宝是我发小」。
- render_html: 渲染一个 HTML 组件卡片插入聊天（端侧 WebView 渲染，支持内联 CSS/JS 动画与交互）。
- run_gallery_script: 在端侧沙箱执行 JavaScript 做相册盘点/统计分析（取数类 handler 只读、数据不出端；删除/收藏等写操作走 capability.dispatch，会弹窗经用户确认）。
- search_media: 搜索本地相册。
- select_media: 选择/取消选择媒体。
- share_media: 分享媒体。
- start_tag_scan: 查询 TAG 扫描状态（人脸/标签/语义索引进度）。
- switch_face_engine: 切换人脸检测引擎。
- switch_view_mode: 切换相册视图。
- toggle_setting: 切换开关型设置。
- view_media: 查看指定媒体。
