交互与工程批注

分流混合判定：render_html 新增 display: inline|fullpage；端侧测高 > 1.0 屏强制降级预览卡，LLM 误判有兜底。
预览固定高 ≈ 0.5 屏；WebView 真实渲染（所见即所得），透明触控层吃掉全部触摸 → 点击任意处进全屏，竖拖落回聊天列表，零手势冲突。
渐隐底部 120px 渐隐遮罩 + 「点击查看完整内容」提示条（accent 色 + ⤢ 图标），明确传达「还有更多」。
全屏顶栏 = ✕ + 标题（取 summary）；同沙箱（零 JS 桥 / 禁 DOM Storage / 远程 script 已剔除）；允许竖滚、显示滚动条；<a> 外链仍走现有落地页浮层。
兜底预览卡渲染失败 → 原生封面兜底（summary + 提示条），不白屏；判定结果随消息持久化，会话重开形态稳定。
Prompt契约更新：inline 卡建议 ≤ 0.66 屏；长报告/多屏内容必须声明 fullpage；LLM 据此决定内容排版策略。
