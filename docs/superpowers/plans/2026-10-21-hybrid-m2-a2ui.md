# Hybrid M2：A2UI L1 卡槽位填充 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 云端 Agent 经 `render_ui` 工具下发 A2UI JSON 骨架，Android 端用 `androidx.a2ui` 官方渲染器原生渲染成聊天卡，数据经 `local://` handle 端上补全（HandleResolver），缺失时降级投影级占位卡，交互态确定性持久化。

**Architecture:** parts 协议零改动（D1）——新增 `data_ui` part 子类型承载 A2UI 信封 JSON；A2UI 只作线格式包在自有 catalog 抽象后（D6），catalog = material3 官方基础目录 + 自研 BarChart 组件合并；handle 全链路 = gallery 工具注册 opaque token（过投影闸上行）→ 云端 LLM 在 updateDataModel 字符串值写 `local://` 绑定（下行不过闸）→ 端上 HandleResolver 解析填槽喂 A2uiMessageProcessor。编排在云（D8），端上无任何 outbound 通道（不挂 `collectMessages`，天然满足 §3.4 不变式）。

**Tech Stack:** Kotlin / KMP `:shared`（commonMain 纯度）/ Jetpack Compose / `androidx.a2ui` **1.0.0-alpha01**（`a2ui-model` + `a2ui-engine` + `androidx.a2ui.compose:compose-runtime/compose-ui` + `androidx.compose.material3:material3-a2ui`，全部 AAR-only 纯 Android，只进 androidApp）/ Room（DB v26→v27）/ Koog server（`@Tool` 反射派发）/ kotlinx-serialization / kotlinx-datetime（shared 已有）。

**Spec:** `docs/superpowers/specs/2026-10-21-cloud-local-hybrid-a2ui-genui-design.md`（§5 US-2/US-4/US-6/US-7、§6 D1-D8、§7 测试接缝 3/4/6、§9 M2 任务标记 [agent-task:hybrid-m2-a2ui]）

## Global Constraints

以下逐字摘自 spec 与仓库治理，所有任务默认遵守：

- 「**协议不动、编排在云、执行在端、出端只过投影、全量靠 handle 本地补全、GenUI 只生成骨架不生成数据。**」（spec §2）
- D1：parts 协议零改动，新语义全走约定（data-* / partId / 状态机）。
- D2：完整结果引用式（handle），不内联。
- D3：投影边界 = 工具注册的 projectionSchema，代码裁剪非 LLM 自觉。
- D6：A2UI 只作线格式，包在自有 catalog 抽象后；CHAT_CARD_CATALOG 仍是 SSOT。
- §3.4 不变式：「GenUI 沙箱/卡片的任何外向通道（capability.dispatch、日志、错误上报）只许携带投影级数据。」
- §8：iOS 完整跟随不在 M1/M2（M1/M2 Android-only）；OpenUI 不作为运行期方案进入任何环节（D4）。
- §9：每步不破 parts 协议，可独立合 main。
- §10 [I18N]：L1 卡静态 label 一律传 string key 由端上查表；动态内容（LLM 写的句子）豁免。端上自建文案（降级占位卡等）五语同步：values / values-es / values-fr / values-zh-rCN / values-zh-rTW，禁硬编码。
- shared commonMain 纯度：禁 `android.*`/`java.*` import、禁裸 `@Volatile`、禁通配 import、lambda 显式参数禁裸 `it`。
- design token 只走 codegen（design-tokens.json → gen-design-tokens.py），禁手改生成物；渲染色值经 `MaterialTheme.appColors`。
- 工作区隔离：在 `.worktrees/` 专用 worktree + 专用分支 `feat/hybrid-m2-a2ui` 施工；commit 前 `git status` 查全量暂存区，只 add 本任务文件；中文 conventional-commit；不 push 远端。
- server 侧 `DeviceToolService` / Swift 侧持 `CloudAgentToolContract` 字面量副本：改动 contract 常量必须双向核对（本计划只新增 `TOOL_RENDER_UI`，存量常量不动）。
- M2 Acceptance：US-2（混合渲染）、US-4（A2UI 原生卡 + token）、US-6（跨端降级）、US-7（交互确定性）。

## 已核实的 API 事实（androidx.a2ui 1.0.0-alpha01 sources jar 逐字核验）

实施者不需要重新调研，以下签名全部从官方 sources jar 提取：

- 解析：`A2uiJsonMessageParser(jsonReaderProvider: (String) -> A2uiJsonReader)`；`.parse(input: String): A2uiServerToClientMessage`——**单信封一 parse**，多信封抛 `A2uiValidationException`；`SUPPORTED_VERSIONS = ["v0.9", "v0.9.1"]`。
- **`A2uiJsonReader` 三端 artifact 均无平台实现，须自写**（Task 6 给完整 ~90 行 Android 适配器）。
- 处理器（compose-ui 顶层工厂函数）：`A2uiMessageProcessor(catalogs: List<A2uiCatalog>, interceptors: List<A2uiActionInterceptor> = emptyList())`；`activeSurfaces: StateFlow<List<A2uiSurfaceModel>>`（`A2uiSurfaceModel.id: String`）；`processMessage(message)` 非挂起；便捷扩展 `processor.processInput(parser, input)`。
- 信封（`androidx.a2ui.model.protocol`）：`A2uiCreateSurfaceMessage(surfaceId, catalogId, theme: Map = emptyMap(), shouldSendDataModel: Boolean = false)`；`A2uiUpdateComponentsMessage(surfaceId, components: List<A2uiComponentPayload>)`；`A2uiUpdateDataModelMessage(surfaceId, path: String = "/", value: Any? = null)`（**HandleResolver 填槽直接构造此类**）；`A2uiDeleteSurfaceMessage(surfaceId)`。
- catalog：`A2uiCatalog(catalogId, components: List<A2uiComponent>, functions = emptyList(), themeSchema = null, isInline = false)`（重名抛 IllegalArgumentException）；`A2uiCatalog.components: A2uiComponentCollection`（`: List`，**可用 `material.components + 自定义组件` 合并**）；`toJsonSchemaString()`。
- 官方基础目录：`materialA2uiBasicCatalogV1(image, video, audioPlayer, urlOpener, messageFormatter, localeProvider, text/icon/row/column/list/card/tabs/modal/divider/button/textField/checkBox/choicePicker/slider/dateTimeInput = MaterialA2uiBasicCatalogV1Defaults.*)`——**前 6 个无默认必填**，类型分别为 `A2uiBasicCatalogV1.Image/Video/AudioPlayer`（组件接口）+ `A2uiUrlOpener/A2uiMessageFormatter/A2uiLocaleProvider`（宿主 fun interface，在 `androidx.a2ui.model.catalog.functions`）。
- 前 3 个经 defaults 工厂构造：`MaterialA2uiBasicCatalogV1Defaults.image(A2uiImageRenderer)` / `.video(A2uiVideoRenderer)` / `.audioPlayer(A2uiAudioPlayerRenderer)`。renderer 均为 `@Composable` fun interface：
  - `A2uiImageRenderer.Image(url: String, contentDescription: String?, contentScale: ContentScale, modifier: Modifier, onError: (Throwable?) -> Unit)`（官方示例即 Coil AsyncImage）
  - `A2uiVideoRenderer.Video(url: String, modifier: Modifier, onError: (Throwable?) -> Unit)`
  - `A2uiAudioPlayerRenderer.AudioPlayer(...)`（同型）
- 宿主接口：`A2uiUrlOpener.openUrl(url: String)`；`A2uiMessageFormatter.format(pattern: String, locale: Locale, arguments: Map<String, Any>): String`（ICU 语法，Android 用 `android.icu.text.MessageFormat`）；`A2uiLocaleProvider.getLocale(): Locale`，有 `@JvmField A2uiLocaleProvider.Default`。
- 组件接口 `A2uiComponent`：`name/description/properties: List<A2uiProperty<*>>` + `@Composable A2uiComponentScope.isReady(properties): Boolean = true` + `@Composable A2uiComponentScope.Content(properties: A2uiComponentProperties, modifier: Modifier)`。
- 属性：`A2uiProperty.dynamicString(key, required = false, description = null): DynamicA2uiProperty<String?>` / `dynamicNumber/dynamicBoolean/dynamicValue/dynamicStringList/dynamicCustom` 等；`@Composable fun <T : Any> A2uiComponentProperties.bind(property: DynamicA2uiProperty<T>): T?`（数据未到/类型错返 null，bind 的响应式读取驱动 isReady 重评估）。
- scope：`A2uiComponentScope.dispatchAction(actionPayload: Map<String, Any?>)`——payload 键约定（A2uiUserActionParser 逐字）：`mapOf("event" to mapOf("name" to <String>, "context" to mapOf(...)))` → `A2uiEventAction(eventName, context)`；或 `"functionCall" to mapOf("call" to ..., "args" to ...)`。其它键 `error()`。
- 拦截：`A2uiActionInterceptor { action: A2uiUserAction -> A2uiUserAction? }`（suspend；**返 null = 消费动作不上行**）；`A2uiUserAction` 有 `surfaceId/componentId/timestamp`。
- 渲染：`A2uiSurface(surfaceModel, modifier, loadingContent = { A2uiSurfaceDefaults.LoadingIndicator() }, errorContent = { A2uiSurfaceDefaults.ErrorFallback(it) }, transitionSpec = ...)`（material3-a2ui）。

```kotlin
package com.mamba.picme.domain.chat.a2ui

/**
 * A2UI 卡契约（D6 隔离层 SSOT）——线格式字面量与 local:// handle 格式的唯一出处。
 *
 * 三方消费：androidApp（渲染/落库/工具注册）、server `RenderUiToolService`（@LLMDescription
 * 字面量副本，改动须双向同步核对）、云端 LLM 行为约定（render_ui 工具描述内嵌）。
 *
 * handle 双形态（spec §3.2 + 投影闸约束）：
 * - 上行投影文本只带 opaque token（[formatHandleToken]，无 scheme，过 CloudToolProjectionGate）；
 * - 下行 A2UI JSON 的 updateDataModel 字符串值写完整 `local://` 绑定（下行不经闸）；
 * - 端上 HandleResolver 用 [parseLocalHandle] 解析填槽。
 */
object A2uiCardContract {

    /** ChatMessageEntity.type / converter 分支键。 */
    const val PART_TYPE = "data_ui"

    /** polang A2UI catalog 唯一 id（createSurface.catalogId 必须等于它）。 */
    const val CATALOG_ID = "https://polang.mamba.com/a2ui/catalog/v1"

    const val HANDLE_SCHEME = "local://"

    /** 相册扫描结果域（search_media / refine_media_search 命中集）。 */
    const val DOMAIN_SCAN = "scan"

    /** A2UI 协议版本（SUPPORTED_VERSIONS = ["v0.9", "v0.9.1"]，M2 固定 v0.9）。 */
    const val PROTOCOL_VERSION = "v0.9"

    /** 上行 opaque token：`handle: scan/<id>`（无 scheme，过投影闸）。 */
    fun formatHandleToken(domain: String, id: String): String = "handle: $domain/$id"

    /** 完整 handle 线格式：`local://<domain>/<id>[#<fragment>]`。 */
    fun formatLocalHandle(handle: LocalHandle): String = buildString {
        append(HANDLE_SCHEME).append(handle.domain).append('/').append(handle.id)
        handle.fragment?.let { fragment -> append('#').append(fragment) }
    }

    /**
     * 解析 `local://<domain>/<id>[#<fragment>]`；非 local:// 或缺 domain/id 返 null。
     * fragment 允许为空字符串以外的任意非空片段（交互态编码由消费方自定）。
     */
    fun parseLocalHandle(value: String): LocalHandle? {
        if (!value.startsWith(HANDLE_SCHEME)) return null
        val rest = value.removePrefix(HANDLE_SCHEME)
        val hashIndex = rest.indexOf('#')
        val pathPart = if (hashIndex >= 0) rest.substring(0, hashIndex) else rest
        val fragment = if (hashIndex >= 0) rest.substring(hashIndex + 1) else null
        val slashIndex = pathPart.indexOf('/')
        if (slashIndex <= 0 || slashIndex == pathPart.length - 1) return null
        return LocalHandle(
            domain = pathPart.substring(0, slashIndex),
            id = pathPart.substring(slashIndex + 1),
            fragment = fragment?.takeIf { it.isNotEmpty() },
        )
    }
}

/** local:// handle 的结构化形态。 */
data class LocalHandle(
    val domain: String,
    val id: String,
    val fragment: String? = null,
)

package com.mamba.picme.data.local

import java.security.SecureRandom

/** HandleResolver 的取数接缝（Task 7 单测 fake 此接口）。 */
interface HandleLookup {
    suspend fun payloadOf(domain: String, handleId: String): String?
}

/**
 * local:// handle 注册/解析入口。handleId = 12 位随机 hex（对云 opaque，无可猜语义）。
 */
class LocalHandleStore(
    private val dao: LocalHandleDao,
    private val random: SecureRandom = SecureRandom(),
) : HandleLookup {

    suspend fun put(domain: String, payloadJson: String): String {
        val handleId = random.nextLong().toULong().toString(16).takeLast(12).padStart(12, '0')
        dao.upsert(
            LocalHandleEntity(
                handleId = handleId,
                domain = domain,
                payloadJson = payloadJson,
                createdAt = System.currentTimeMillis(),
            )
        )
        return handleId
    }

    override suspend fun payloadOf(domain: String, handleId: String): String? {
        val row = dao.byId(handleId) ?: return null
        return row.payloadJson.takeIf { row.domain == domain }
    }
}

package com.mamba.picme.features.chat.a2ui

import androidx.a2ui.model.processor.A2uiJsonReader
import androidx.a2ui.model.processor.A2uiJsonToken
import java.io.StringReader

/** android.util.JsonReader → A2uiJsonReader 适配器（androidx.a2ui 未附带平台实现）。 */
class AndroidA2uiJsonReader(input: String) : A2uiJsonReader {

    private val reader = android.util.JsonReader(StringReader(input))

    override fun peek(): A2uiJsonToken =
        when (reader.peek()) {
            android.util.JsonToken.BEGIN_ARRAY -> A2uiJsonToken.BEGIN_ARRAY
            android.util.JsonToken.END_ARRAY -> A2uiJsonToken.END_ARRAY
            android.util.JsonToken.BEGIN_OBJECT -> A2uiJsonToken.BEGIN_OBJECT
            android.util.JsonToken.END_OBJECT -> A2uiJsonToken.END_OBJECT
            android.util.JsonToken.NAME -> A2uiJsonToken.NAME
            android.util.JsonToken.STRING -> A2uiJsonToken.STRING
            android.util.JsonToken.NUMBER -> A2uiJsonToken.NUMBER
            android.util.JsonToken.BOOLEAN -> A2uiJsonToken.BOOLEAN
            android.util.JsonToken.NULL -> A2uiJsonToken.NULL
            android.util.JsonToken.END_DOCUMENT -> A2uiJsonToken.END_DOCUMENT
        }

    override fun beginObject() = reader.beginObject()

    override fun endObject() = reader.endObject()

    override fun beginArray() = reader.beginArray()

    override fun endArray() = reader.endArray()

    override fun hasNext(): Boolean = reader.hasNext()

    override fun nextName(): String = reader.nextName()

    override fun nextString(): String = reader.nextString()

    override fun nextBoolean(): Boolean = reader.nextBoolean()

    override fun nextDouble(): Double = reader.nextDouble()

    override fun nextInt(): Int = reader.nextInt()

    override fun nextLong(): Long = reader.nextLong()

    override fun nextNull() = reader.nextNull()

    override fun skipValue() = reader.skipValue()

    override fun close() = reader.close()
}
```

> `android.util.JsonReader` 是 Android 框架类，JVM 单测不可用——本类由真机冒烟覆盖；解析正确性另有保证：`A2uiJsonMessageParser` 的校验逻辑在 a2ui-model 纯 Kotlin 层，Robolectric 若有需要后续再补。

import androidx.a2ui.compose.ui.A2uiMessageProcessor
import androidx.a2ui.model.processor.A2uiActionInterceptor

import androidx.a2ui.model.processor.A2uiServerToClientMessage
import androidx.a2ui.model.protocol.A2uiEventAction

/**
 * data_ui 卡的渲染宿主：一颗 processor 一张卡（surface 粒度隔离，互不重放串台）。
 *
 * §3.4 不变式落点：不挂 outboundEvents 收集器（无任何上行通道）；用户交互经
 * A2uiActionInterceptor 本地消费（返 null），只触发 onBucketSelected 回调写本地交互态。
 */
@Composable
fun A2uiCardHost(
    surfaceId: String,
    resolvedMessages: List<A2uiServerToClientMessage>,
    catalog: A2uiCatalog,
    onBucketSelected: (bucketLabel: String) -> Unit,
    modifier: Modifier = Modifier,
) {
    val processor = remember(surfaceId) {
        A2uiMessageProcessor(
            catalogs = listOf(catalog),
            interceptors = listOf(
                A2uiActionInterceptor { action ->
                    if (action is A2uiEventAction &&
                        action.eventName == PolangBarChartComponent.EVENT_SELECT_BUCKET
                    ) {
                        (action.context["bucket"] as? String)?.let(onBucketSelected)
                        null // 消费：不上行
                    } else {
                        null // M2 一切动作本地消费，不出端
                    }
                }
            ),
        )
    }
    remember(resolvedMessages) {
        resolvedMessages.forEach { message -> processor.processMessage(message) }
        true
    }
    val surfaces by processor.activeSurfaces.collectAsState()
    val surface = surfaces.firstOrNull { it.id == surfaceId }
    if (surface != null) {
        A2uiSurface(surfaceModel = surface, modifier = modifier)
    }
}

/** messagesJson（信封 JSON 数组）逐封解析——A2uiJsonMessageParser 单信封一 parse。 */
fun parseA2uiEnvelopes(messagesJson: String): List<A2uiServerToClientMessage> {
    val parser = A2uiJsonMessageParser { input -> AndroidA2uiJsonReader(input) }
    val trimmed = messagesJson.trim()
    require(trimmed.startsWith("[") && trimmed.endsWith("]")) {
        "messagesJson 必须是信封 JSON 数组"
    }
    // 数组逐元素切分：元素均为 JSON 对象，用 JsonReader 流式切
    val envelopes = mutableListOf<A2uiServerToClientMessage>()
    val reader = android.util.JsonReader(java.io.StringReader(trimmed))
    reader.beginArray()
    while (reader.hasNext()) {
        val start = markReaderPosition(reader) // 见实现注
        envelopes += parser.parse(readRawJsonObject(reader))
    }
    reader.endArray()
    return envelopes
}

```kotlin
package com.mamba.picme.features.chat.a2ui

import androidx.a2ui.model.protocol.A2uiServerToClientMessage
import androidx.a2ui.model.protocol.A2uiUpdateDataModelMessage
import com.mamba.picme.data.local.HandleLookup
import com.mamba.picme.domain.chat.a2ui.A2uiCardContract
import com.mamba.picme.domain.chat.a2ui.GalleryHistogramBuilder
import com.mamba.picme.domain.chat.a2ui.HistogramBucket
import com.mamba.picme.domain.chat.a2ui.ScanPhotoEntry
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import kotlinx.datetime.TimeZone
import kotlinx.serialization.json.Json
import org.json.JSONArray
import org.json.JSONObject

/** HandleResolver 输出：填槽完成 or 降级（US-6）。 */
sealed interface A2uiResolution {
    data class Ready(val messages: List<A2uiServerToClientMessage>) : A2uiResolution
    data class Degraded(val reason: String) : A2uiResolution
}

/**
 * local:// handle → 本地全量数据填槽（spec §3.2；GenUI 只生成骨架不生成数据）。
 *
 * 扫描 messagesJson 信封数组：updateDataModel 的字符串值若以 local:// 开头，解析 handle →
 * HandleLookup 取 payload → 按 domain 算数据（scan=月桶）→ 替换为结构化值重新构造信封。
 * 任一 handle 缺失/不可解析 → 整张卡 Degraded（宁缺毋滥，不混真假数据）。
 */
class HandleResolver(
    private val lookup: HandleLookup,
    private val timeZone: TimeZone = TimeZone.currentSystemDefault(),
    private val json: Json = Json { ignoreUnknownKeys = true },
) {

    suspend fun resolve(surfaceId: String, messagesJson: String): A2uiResolution =
        withContext(Dispatchers.Default) {
            val array = runCatching { JSONArray(messagesJson) }
                .getOrElse { return@withContext A2uiResolution.Degraded("messages_json_malformed") }
            val filled = mutableListOf<A2uiServerToClientMessage>()
            for (index in 0 until array.length()) {
                val envelope = array.getJSONObject(index)
                val dataModel = envelope.optJSONObject("updateDataModel")
                if (dataModel == null) {
                    filled += parseEnvelope(envelope)
                        ?: return@withContext A2uiResolution.Degraded("envelope_invalid")
                    continue
                }
                val value = dataModel.opt("value")
                if (value !is String || !value.startsWith(A2uiCardContract.HANDLE_SCHEME)) {
                    filled += parseEnvelope(envelope)
                        ?: return@withContext A2uiResolution.Degraded("envelope_invalid")
                    continue
                }
                val handle = A2uiCardContract.parseLocalHandle(value)
                    ?: return@withContext A2uiResolution.Degraded("handle_malformed")
                val payload = lookup.payloadOf(handle.domain, handle.id)
                    ?: return@withContext A2uiResolution.Degraded("handle_missing")
                val replacement: Any = when (handle.domain) {
                    A2uiCardContract.DOMAIN_SCAN -> {
                        val entries = runCatching {
                            json.decodeFromString<List<ScanPhotoEntry>>(payload)
                        }.getOrElse { return@withContext A2uiResolution.Degraded("payload_malformed") }
                        GalleryHistogramBuilder.buildMonthly(entries, timeZone).toPlainList()
                    }
                    else -> return@withContext A2uiResolution.Degraded("domain_unknown")
                }
                filled += A2uiUpdateDataModelMessage(
                    surfaceId = dataModel.optString("surfaceId", surfaceId),
                    path = dataModel.optString("path", "/"),
                    value = replacement,
                )
            }
            A2uiResolution.Ready(filled)
        }

    private fun parseEnvelope(envelope: JSONObject): A2uiServerToClientMessage? =
        runCatching {
            A2uiJsonMessageParser { input -> AndroidA2uiJsonReader(input) }
                .parse(envelope.toString())
        }.getOrNull()

    private fun List<HistogramBucket>.toPlainList(): List<Map<String, Any>> =
        map { bucket -> mapOf("label" to bucket.label, "count" to bucket.count) }
}
```

> `A2uiJsonMessageParser` import 与 `parseA2uiEnvelopes` 同款；若 Task 6 已把 parser 工厂提成共享私有函数，复用之，不复制。
