## 1. 概述

本文档整合了两套主流人脸关键点标准：

- **MediaPipe Face Mesh**：468 个 3D 人脸关键点，用于实时人脸网格检测。
- **火山引擎 106 点标准**：与商汤/Face++ 106 点标准一致，是行业通用的人脸关键点检测规范，也是 PoLang 美颜/滤镜管线的内部标准。

本文档同时提供 **MediaPipe 468 → 火山 106 的映射策略**，供 `MediaPipe468Adapter.kt` 与 `FaceLandmarkOverlay.kt` 参考实现。

> **坐标系说明**：MediaPipe 与火山引擎均返回归一化坐标（0-1），原点(0,0)在左上角，x轴向右，y轴向下。前置摄像头需要水平镜像（`x = 1 - x`）。详见 [`docs/07-STANDARDS/COORDINATE_SYSTEM.md`](07-STANDARDS/COORDINATE_SYSTEM.md)。

### 2.3 火山 106 点注意事项

1. **镜像说明**：本文档中的"左/右"是基于**被摄者真实面部**（前置摄像头镜像后）。画面左侧=实际右脸，画面右侧=实际左脸。
2. **轮廓方向**：轮廓 0-32 为开放曲线，从右脸鬓角（索引0，画面左侧）开始，经过下巴（索引16），到左脸鬓角（索引32，画面右侧）结束。
3. **瞳孔位置**：104/105 与 74/77 位置接近，用于需要瞳孔中心点的场景。
4. **对称性**：左右脸关键点应保持对称分布，映射时需确保左右对称性。

### 3.2 对称规则说明

MediaPipe Face Mesh 的面部关键点关于**面部中轴线**（垂直中心线）对称。

- **左侧点**：位于画面左侧（被摄者右脸）
- **右侧点**：位于画面右侧（被摄者左脸）
- **中心点**：位于面部中轴线上，无对称点

**对称规律**：大多数对称对满足 `左侧索引 + 右侧索引 ≈ 500`，但存在例外。

### 3.12 MediaPipe 注意事项

1. **坐标系定义**：
   - MediaPipe 返回的坐标为归一化坐标（0-1）
   - 原点(0,0)在左上角
   - x轴向右，y轴向下
2. **前置摄像头镜像**：
   - 使用前置摄像头时，需要水平镜像：`x = 1 - x`
   - 镜像后，"左侧"和"右侧"互换
3. **对称精度**：
   - 理想情况下，对称点的y坐标应该完全相同
   - x坐标应该关于0.5对称（即 `x_left + x_right = 1.0`）
   - 实际检测中存在微小偏差是正常的
4. **中心点处理**：
   - 位于面部中轴线上的点没有对称点
   - 包括：鼻尖(4)、鼻梁(6, 168, 195, 197)、唇珠(0)等
5. **特殊情况**：
   - 某些对称对不严格遵循 `left + right = 500` 规律
   - 建议通过实际坐标验证对称性
6. **轮廓差异**：
   - MediaPipe FACE_OVAL 为36点闭合曲线（含额头）
   - 106点标准为33点开放曲线（不含额头）
   - 映射时需要选择不含额头的 MediaPipe 轮廓点
7. **瞳孔检测**：
   - 需要开启 `refine_landmarks=True`
   - 瞳孔点索引为 468-475（478点模式）
8. **左右定义**：
   - MediaPipe 中的"左/右"是基于**观察者视角**，与106点标准一致
9. **深度信息**：
   - MediaPipe 每个点包含 (x, y, z) 三维坐标，z轴以鼻尖为原点

### 3.13 对称性验证方法

```kotlin
// 检查两个点是否关于面部中轴线对称
fun isSymmetric(leftPoint: Pair<Float, Float>, rightPoint: Pair<Float, Float>): Boolean {
    val centerX = 0.5f // 面部中轴线x坐标
    val tolerance = 0.02f // 容差

    // x坐标应该关于中心对称
    val xSymmetric = Math.abs((leftPoint.first + rightPoint.first) - 1.0f) < tolerance

    // y坐标应该接近
    val ySimilar = Math.abs(leftPoint.second - rightPoint.second) < tolerance

    return xSymmetric && ySimilar
}

// 大多数对称对满足：左侧索引 + 右侧索引 ≈ 500
fun checkSymmetryIndex(leftIndex: Int, rightIndex: Int): Boolean {
    val sum = leftIndex + rightIndex
    return sum in 490..510 // 允许±10的误差
}
```

## 4. MediaPipe 468 → 火山 106 映射策略

### 4.1 核心映射原则

#### 第一性原理

**MediaPipe 468 点本身的拓扑结构不对称**，因此不能简单使用几何镜像（`x = 1-x`），而必须：

1. **先确定语义对称的固定点**：为每个 106 点找到 MediaPipe 中语义对应的固定点
2. **再插值过渡点**：在固定点之间使用 `midPoint` 插值
3. **验证左右对称性**：确保 M0-M15 与 M17-M32 关于 M16 对称

#### 左右对称定义

- **中轴点**：M16=152（下巴中心）
- **右半边**：M0-M15（画面左侧=被摄者右脸，从上到下）
- **左半边**：M17-M32（画面右侧=被摄者左脸，从下到上）
- **对称验证**：每个 M_i 与 M_(32-i) 应关于中轴线对称
