共享内核原则

:shared 只有一份
Agent 编排核心在 commonMain；Android 组合根注入、iOS XCFramework 消费
commonMain 纯度门禁
无 @Composable / 平台 import / actual；checkCommonMainPurity 编译期强制（ADR-013）
端云分工
端侧：媒体处理 + VLM 打标 + 人脸检测；云端：文本推理 + 账号 + 网关
