架构要点

端侧隐私优先
人脸 / OCR / 打标 100% 端内，媒体文件不上云（ADR-008 红线）
KMP 单一代码库
commonMain 引擎无关编排逻辑，Android / iOS 双端共享（ADR-013）
一套内核 · 双端落地
iOS 经 SharedKit XCFramework 接入同一 :shared；/ios-follow 对齐流水线保证 parity
自研渲染引擎
OpenGL ES + EGL 全 GPU 管线，GPUPixel 已完全移除，零三方 SDK
本地 / 远程分离
端侧只留 VLM 打标，文本推理走远程 OpenAI 兼容协议（ADR-005）
零拷贝 GPU 预览
CameraX → GL → SurfaceView 全程 GPU，预览禁 glReadPixels
