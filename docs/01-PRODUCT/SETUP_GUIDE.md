# PoLang 破浪相册 · 使用前提与首次设置指南

> **定位**：新用户「如何把 PoLang 真正用起来」的唯一事实来源（SSOT），供官网帮助页 / Google Play 商店说明复用。
> **维护**：与 [`FEATURES.md`](./FEATURES.md)、[`03-TECHNICAL-SPECS/TAG_GENERATION.md`](../03-TECHNICAL-SPECS/TAG_GENERATION.md) 保持一致；模型清单以 `androidApp/src/main/res/raw/llm_models.json` 为准。
> **最后更新**：2026-09-18（Pass 扫描入口改为「整理」页 SCAN tab）

---

## 为什么需要这份指南

PoLang 的智能搜索 / AI 对话 / 人物识别**不是「装完即用」**的——它们依赖**端侧 AI 模型**和**对相册的一次性扫描打标**。如果跳过下面的准备步骤，你会遇到「搜不到照片」「AI 答非所问」「搜索像没反应」等情况，但这不是 App 坏了，而是**还没准备好**。

**一句话**：先下模型 → 开后台保活跑一次扫描 →（可选）注册账号 / 标注人物 / 配远程通道，AI 才真正「懂事」。

---

## 使用前提总览（7 条）

| # | 前提 | 必要性 | 大致耗时 / 体积 |
|---|------|--------|-----------------|
| ① | 下载「必须」模型 | **必需** | ~1.5 GB，建议 WiFi |
| ② | 执行 Pass 1 扫描（人脸 + 语义） | **必需**（最小可用） | ~1.5 h / 万张 |
| ③ | 执行 Pass 3 扫描（图片内容理解） | 推荐（更精准） | ~24 h / 万张 |
| ④ | 注册账号获取免费额度 | 视用量 | 约 1 分钟 |
| ⑤ | 人物标注 + AI 记忆 | 可选（让 AI 更聪明） | 按需 |
| ⑥ | 飞书 / Telegram 远程控制 | 可选（进阶） | 约 5 分钟 |
| ⑦ | 备份与恢复 | 可选（换机 / 重装前） | 按需 |

> ①② 是「能用」的最低门槛；③④⑤⑥⑦ 是「好用 / 进阶」的增强。完成 ①② 后即可开始体验，其余按需补充。

---

## ① 下载「必须」模型（~1.5 GB）

**入口**：相册首页 → 模型中心 →「必须」Tab。（首次进入相册时 App 会弹窗「下载相册必备模型」，点「一键下载」即可。）

相册的打标、人脸识别、语义搜索都依赖端侧模型，**缺一个都会导致对应能力不可用**。7 个必须模型合计约 1.5 GB：

| 模型 | 用途 | 体积 |
|------|------|------|
| 2D106 Landmark | 106 点人脸关键点 | 4.75 MB |
| RetinaFace Det500M | 人脸检测（ROI 区域） | 1.23 MB |
| Glint360K R100 | 人脸特征提取（512 维 embedding） | 248 MB |
| MobileCLIP-S2 | 图文语义编码（语义搜索核心） | 381 MB |
| Florence-2-Base | 图像内容打标（Pass 3 用） | 266 MB |
| OPUS-MT 中英翻译 | 中文查询 → 英文（语义搜索） | 233 MB |
| OPUS-MT 英中翻译 | 英文打标摘要 → 中文 | 423 MB |

**「推荐」模型（可选增强）**：模型中心 →「推荐」Tab。

- **MODNet / U2NetP**：人像抠图 / 证件照。
- **Sherpa-ONNX**：语音输入 / 唤醒词。
- 可开启「Wi-Fi 下自动下载推荐模型」开关，在 WiFi 下静默预下载。

> 🔒 **隐私**：人脸检测 / 打标 / 分类等媒体处理 **100% 端侧**完成，用户图片/视频**文件不会上传**到远程推理服务器；远程仅用于对话文本与相册摘要（详见 ADR-008）。

## ② 执行 Pass 1 扫描（最小可用，~1.5 h / 万张）

**入口**：底部 Tab「整理」→「扫描」（即 TAG 生成控制页；2026-09-06 起打标入口并入整理页 SCAN tab，不再从设置进入）。

Pass 1 = UI 中的 **第一步：人脸检测与语义编码**。它对每张照片做人脸检测 + 人脸特征 + MobileCLIP 语义向量，并自动衔接 **第二步：人物聚类**（把同一个人的脸归成一类）。这是让「找人」「按语义搜图」能工作的**最低门槛**。

- 约 **1.5 小时可处理 1 万张照片**（依机型，GPU 加速）。
- 扫描期间保持 App 在前台，**或开启后台保活**（见下方提醒）。

> ⚠️ **重要：开启后台保活**
> 扫描时若 App 退到后台，部分系统（如小米 HyperOS）会冻结进程导致扫描暂停。请按 TAG 生成控制页顶部的黄色提示**开启后台保活**（允许自启动 / 临时关闭省电限制），否则扫描可能永远跑不完。

完成 ①② 后，你已经可以体验基本的「找人 / 语义搜图」和 AI 对话了。

---

## ③ 执行 Pass 3 扫描（更精准，~24 h / 万张）

**入口**：同 TAG 生成控制页 → **第三步：图片内容理解**。

Pass 3 = UI 中的 **第三步：图片内容理解**，用 Florence-2（默认）/ Qwen3-VL（备选）为每张照片生成**场景、活动、物体、摘要**等中文标签。它让「搜海边」「找夜景」「一家人野餐」这类自然语言搜索更准。

- 约 **24 小时处理 1 万张照片**——**强烈建议插电 + 连 WiFi + 过夜跑**。
- **分阶段独立控制**：每个阶段都可「增量」补充或「全量」重跑，可随时暂停 / 继续，已处理的照片不会重复。

> ①②③ 三步在 TAG 生成控制页统一管理。后续有新照片入库，用「增量」即可，不必每次全量重扫。

## ④ 注册账号获取免费额度（远程对话）

**入口**：设置 → **账号**（邮箱注册）。

PoLang 的 AI 对话**默认走远程大模型**（体验最佳）。远程推理由自建服务（`api.polang.net`）代理，按账户配给**免费额度**：

- **匿名访客**：额度较小，用完会降级提示。
- **邮箱注册账号**：免费额度提升至 **每月 1000 次**（以服务端实际配置为准）。
- 额度耗尽时 App 会提示，可注册 / 切换账号继续使用。
- 用量可在「设置 / 账号」页查看（如「已用 150 / 1000，剩余 850 次」），可随时刷新。

> 端侧搜索 / 打标不消耗远程额度；额度仅统计远程对话调用。

## ⑤ 人物标注 + AI 记忆（让 AI 更聪明）

扫描完成后，相册会自动识别出人物。你可以**手动补充名称与关系**，让 AI 在对话中「认识」你的家人朋友：

**人物标注**：相册人物页 → 选中某人 → **编辑人物**

- 设置名称（如「妈妈」）。
- 选择关系：
  - **家庭**：爸爸 / 妈妈 / 儿子 / 女儿 / 哥哥 / 姐姐 / 弟弟 / 妹妹 / 爷爷 / 奶奶
  - **配偶 / 恋人**
  - **社会**：朋友 / 同学 / 同事
  - **自定义称呼**（填写后以自定义为准）/ **不设置**
- 勾选「**这是我**」标记本人。

**AI 记忆**：设置 → **AI 记忆**

- 查看 / 编辑 / 删除 AI 记住的事实（如「我有个女儿叫小米」「我喜欢户外摄影」）。
- AI 会在后续对话中运用这些记忆，回答更贴合你。

## ⑥ 飞书 / Telegram 远程控制（可选进阶）

**入口**：设置 → **通信通道**。

配置后，你可以**在飞书 / Telegram 里用自然语言远程指挥 App**（如「把昨天拍的风景照发给我」），App 执行后把结果回传到 IM。媒体仅在你自己的 IM 通道与你本人之间流转。

- **飞书**：填 **App ID + App Secret**（自建应用）。
- **Telegram**：填 **Bot Token + 允许的 Chat ID**，**长轮询连接，无需公网 IP**。
- 多通道可并存；在「当前通道」切换为 飞书 / Telegram / 不启用。

---

## ⑦ 备份与恢复（换机 / 重装前）

**入口**：设置 → **备份与恢复**。

打标、人脸聚类、人物关系等成果生成成本高（扫描可能以小时计）。**换机、卸载重装**（尤其是签名不同的包，系统会清空应用数据）前，建议先导出备份：

- **导出**：通过系统文件选择器（SAF）选择保存位置，生成备份文件（格式 v5，含 TAG 数据、人物与人脸 embedding、偏好设置、媒体反馈等全量数据）。
- **导入**：在同一入口选择备份文件即可恢复。
- Release 包即可用，无需 adb / debug 环境。

## 常见问题

- **搜照片没结果 / AI 说找不到**：通常是 Pass 1 / Pass 3 还没扫完，去「TAG 生成控制」页看进度。
- **扫描卡住不动**：检查后台保活是否开启；HyperOS 等系统会冻结后台进程。
- **对话提示额度不足**：设置 → 账号，注册邮箱账号获取更高免费额度。
- **App 提示缺模型**：模型中心 → 必须，把未下载的补齐。
- **新拍了照片搜不到**：对「图片内容理解」执行一次「增量」扫描即可。
